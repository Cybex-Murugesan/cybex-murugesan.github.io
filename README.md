# Murugesan B — Personal Portfolio

A responsive, single-page portfolio with an editorial layout and a Midnight Indigo + Vanilla color palette.

## Preview on Windows
1. Extract this ZIP.
2. Open the `Murugesan_Portfolio_Refresh` folder.
3. Double-click `index.html`. It opens in your browser.
4. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.

## Before publishing
- In `index.html`, replace `YOUR_EMAIL@example.com` with the email address you want visitors to use.
- Replace `https://www.linkedin.com/` with your personal LinkedIn profile URL.
- Check every project description and adjust it to match your current progress.
- Your portrait is stored at `assets/portrait.png`. To change it, replace that file with your new image and keep the same filename.

## Editing with AI (no coding knowledge needed)
You can upload this ZIP to an AI assistant and ask for one change at a time. For example:
- “Change the website's background to a slightly warmer indigo but keep the main palette #282B4A and #EEEBDA.”
- “Rewrite the Writto description without changing the layout.”
- “Make the project cards slightly larger on mobile.”
Ask the AI to return the updated files or a new ZIP. Keep a backup of this working version before making changes.

## Color palette
- Midnight Indigo: `#282B4A`
- Vanilla: `#EEEBDA`

## Notes
- The site uses plain HTML, CSS, and JavaScript. There is no build step and no package installation.
- Google Fonts are loaded online. If offline, the site falls back to system fonts.
- ElvOra is intentionally shown as a separate future-startup teaser (“Something is cooking…”), not as a current project.
- Contact links are placeholders until you update them.
